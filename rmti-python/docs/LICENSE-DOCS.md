# License history

**As of v2.0.0, this entire project — the Python reference implementation
in this repository, the RMTI Calculator spreadsheet, and both interactive
sandboxes (oncology/public-health surveillance and disaster/climate) — is
released under the Apache License 2.0, with no exceptions.** The `LICENSE`
file at the root of this repository, and the matching `LICENSE` file
shipped with each sandbox and the calculator, is the complete grant for
all of it: code, rubric text, tier descriptions, worked examples, and UI
copy alike.

## What changed from v1.1.0

An earlier internal draft of this repository (never published to Zenodo)
split the license: the bare equations and lookup tables were Apache 2.0,
while the rubric wording, tier descriptions, and any interactive sandbox
built on top of them were marked all-rights-reserved. That split is
**retired as of v2.0.0**. The copyright holder (Cesar Marolla) decided the
whole project should be uniformly and permissively licensed, so that
institutions adopting RMTI — health systems, disaster-management agencies,
researchers, practitioners — can use, modify, and redistribute all of it,
code and teaching material alike, under one clear, well-understood license
with no ambiguity about which files a recipient is and isn't free to reuse.
